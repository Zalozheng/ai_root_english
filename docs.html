快速上手

  • 1
    网页划词： 选中文字，点击出现的 🔍 按钮即可开始深度溯源。
  • 2
    右键解析： 选中单词右键菜单选择 AI 词源解析，在侧边栏查看结果。
  • 3
    即点即译： 点击右上角图标直接输入；或开启“图标即译”点击图标立即分析。

情景记忆

AI 能根据您的角色情景讲述不同的词源故事。例如解析 buffer：

🐧 极客模式： 讲解显存、内核队列与数据缓冲。
🏡 生活模式： 讲解沙发靠垫与社交缓冲余地。

提示：您可以在设置中创建无限个自定义角色情景。

引擎配置

方案 A：云端 API

适合希望开箱即用的用户。支持 OpenAI, DeepSeek 等。只需填入 API 地址与 Key 即可。

方案 B：本地 Ollama

适合追求隐私与免费的用户。支持断网可用。推荐使用 RTX 3060 及以上显卡运行 qwen2.5 等模型。

数据安全与管理

所有数据均本地存储，不经过任何服务器。操作时请注意配合“模式开关”使用：

组合模式 功能表现
开启 🌍 仅限当前情景 导入/清除操作将只针对当前选中的角色，不会影响其他情景下的笔记。
开启 📥 替换模式导入 先清空当前选定范围的数据，再将新数据写入。
关闭 📥 替换 (即合并模式) 增量导入，将新记录与本地现有记录无缝合并。
