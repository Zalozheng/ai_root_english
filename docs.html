Ai 词源引擎使用指南

👋 欢迎使用！ 这是一款专为深度英语学习者设计的浏览器插件，它将大语言模型（如 ChatGPT, Ollama）的推理能力与词根词缀记忆法深度结合，为您打造专属的英语特训库。

1. 🚀 快速上手

  • 网页划词： 在任意网页中选中文本，鼠标附近会弹出一个 🔍 图标，点击即可呼出 AI 解析弹窗。
  • 图标即译： 点击浏览器右上角的插件图标，可以直接在弹出的窗口中输入单词进行解析（如果您开启了【图标即点即译】，选中文本后点击图标会立刻开始解析）。
  • 一键发音： 在解析结果中点击 🔊 图标，即可朗读纯正的美式发音。

2. 🎭 核心特色：情景记忆与角色扮演

传统的背单词软件每个单词只有一种解释，但本插件允许您通过【角色与记忆情景】功能，让单词在不同的专业领域“活”起来。

  • 您可以在【⚙️ 引擎偏好设置】中无限添加自定义情景（如：考研英语、律师日常、医学专业）。
  • 当您在“极客模式”下查询 buffer 时，AI 会解释为“缓冲器”，并结合计算机底层逻辑给您画面感。
  • 如果切换到“通用生活”，buffer 可能会被解释为“缓冲物”或“起缓冲作用的人”。

3. ⚙️ AI 引擎配置 (必须配置才能使用)

进入【⚙️ 引擎偏好设置】，您可以选择以下两种引擎之一：

方案 A：自定义云端大模型 (如 OpenAI, DeepSeek, Kimi 等)

适合没有高配置电脑，希望开箱即用的用户。填入您的 API 地址和密钥即可使用。

方案 B：Ollama 本地引擎 (极客推荐)

适合拥有独立显卡（如 RTX 3060 以上）的用户，实现完全免费、断网可用、绝对隐私的本地查词。

  1. 下载并安装 Ollama。
  2. 在终端运行命令下载模型：ollama run qwen2.5 (或 llama3 等)。
  3. 在插件设置中选择【🦙 Ollama 本地引擎】，确保接口地址为 http://127.0.0.1:11434。

4. 🗄️ 数据安全与高阶管理

您的所有数据均保存在您的浏览器本地，不上传任何服务器。请养成定期备份的好习惯。

⚠️ 数据管理面板说明：
设置页底部的导出/导入/清除按钮非常强大，请注意配合上方的【模式开关】使用。
组合模式 功能表现
开启 🌍 仅限当前情景 所有操作（导出、覆盖导入、清除）只会影响您当前选择的情景（例如：只会删掉该单词在极客模式下的笔记，保留日常模式）。
开启 📥 替换模式导入 导入前会先清空当前选定范围的数据，然后将新数据写入。
关闭 📥 合并模式导入 导入时不会删除任何现有数据，而是将新文件中的记录与本地记录无缝合并。

5. 🌳 词树图谱与特训

除了单个单词的记忆，插件还自动为您构建了庞大的词源网络。

  • 在【🌱 词源图谱库】中，您可以查看所有遇到过的词根（如 struct 表示“建造”），并浏览它的所有同根词（construct, destroy）。
  • 点击【🌳 在词树图谱中探索】，会生成一张优美的知识导图，帮您把散落的单词串联成线。
